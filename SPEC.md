## 0. Vision

**[OPEN]** One-paragraph pitch of the game and the feeling it should give the player.

- Original web-slinging superhero in a 3D city (our own character, name, suit and
  world — not a copy of any existing franchise, so it can be shared freely).
- "VR-like" camera: the player can freely change their point of view without VR hardware.
- Runs locally from a single Docker command so friends can play it.
